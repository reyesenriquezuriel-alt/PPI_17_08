Resumen Institucional

El Sistema de Biblioteca UAEMéx permite administrar el catálogo bibliográfico, los usuarios, los préstamos y las reservas desde una sola plataforma.

  • Gestión de libros.
  • Administración de usuarios.
  • Control de préstamos.
  • Seguimiento de reservas.
  • Generación de reportes.
  • Control institucional.
